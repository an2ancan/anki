# Deutsch B1–B2 Anki Mobile

Личное мобильное веб-приложение для изучения немецких слов и грамматики (уровень B1–B2) по методу интервального повторения (Anki) с озвучкой, добавлением собственных карточек и облачной синхронизацией через **Supabase**.

## Возможности

- **70 встроенных карточек** (50 лексических + 20 грамматических B1–B2) с примерами и контекстом.
- **Добавление своих карточек**: быстрая форма (`+` в шапке) и массовый импорт/экспорт CSV.
- **Управление своими карточками**: просмотр, поиск и удаление пользовательских карточек в настройках.
- **Авторизация и синхронизация через Supabase**: вход и регистрация по Email + паролю, сохранение прогресса повторений, дневной статистики и своих карточек в облаке (с защитой Row Level Security).
- **Работа офлайн / без входа**: если Supabase не настроен или пользователь не вошёл, весь прогресс и карточки сохраняются локально в `localStorage`.
- **Озвучка (Web Speech API)**: автоматический выбор качественного немецкого голоса, настройка скорости и тона.
- **Тёмная/светлая тема** и мобильная адаптация.

## Инструкция по настройке Supabase (5 минут)

### Шаг 1. Создайте проект в Supabase
1. Перейдите на [supabase.com](https://supabase.com/) и войдите в аккаунт.
2. Нажмите **New Project**, выберите название, пароль базы данных и регион, затем нажмите **Create new project**.

### Шаг 2. Создайте таблицы и правила безопасности (RLS)
1. В левом меню откройте **SQL Editor** → **New query**.
2. Откройте файл [`supabase_schema.sql`](./supabase_schema.sql) из этого репозитория, скопируйте весь его текст и вставьте в редактор.
3. Нажмите **Run** (Ctrl+Enter). Будут созданы таблицы `user_profiles` и `user_cards` с политиками RLS (каждый пользователь имеет доступ только к своим данным).

### Шаг 3. Настройте авторизацию по Email
1. В левом меню откройте **Authentication** → **Providers** → **Email**.
2. Убедитесь, что **Enable Email provider** включён.
3. *(Опционально, для мгновенного входа без подтверждения письма)* Отключите **Confirm email** и сохраните изменения.

### Шаг 4. Получите ключи подключения
1. Откройте **Project Settings** (иконка шестерёнки внизу слева) → **API** (или **Data API / API Keys**).
2. Скопируйте:
   - **Project URL** (например, `https://abcdefghijkl.supabase.co`)
   - **anon / public key** (или **Publishable key** `sb_publishable_...`)

### Шаг 5. Подключите Supabase к приложению

Вы можете подключить ключи любым из двух способов:

- **Способ А (рекомендуется для GitHub Pages / нескольких устройств):**
  Откройте `index.html`, найдите объект `SUPABASE_CONFIG` в начале `<script>` и вставьте свои значения:
  ```js
  const SUPABASE_CONFIG = {
    url: 'https://YOUR_PROJECT_ID.supabase.co',
    anonKey: 'YOUR_SUPABASE_ANON_KEY'
  };
  ```
  > `anonKey` (публичный ключ) безопасно хранить в клиентском коде, так как доступ к данным ограничен правилами **Row Level Security (RLS)** из `supabase_schema.sql`.

- **Способ Б (без редактирования кода):**
  Откройте приложение в браузере → нажмите кнопку **Войти** в правом верхнем углу → раскройте **Настройки Supabase** → вставьте URL и Anon Key → нажмите **Сохранить**.

## Как пользоваться приложением

1. **Запуск:**
   - Просто откройте `index.html` в браузере или опубликуйте репозиторий через **GitHub Pages** (*Settings → Pages → Deploy from branch `main`*).
2. **Вход и синхронизация:**
   - Нажмите иконку профиля (**Войти**) в шапке.
   - Зарегистрируйтесь или войдите по Email и паролю.
   - Прогресс и добавленные карточки синхронизируются автоматически после каждого ответа или добавления карточки. Также доступна кнопка **Синхронизировать сейчас**.
3. **Добавление своих карточек:**
   - Нажмите кнопку **`+`** в шапке.
   - Заполните немецкое слово/фразу, русский перевод и (по желанию) примеры, контекст и теги.
   - Новая карточка сразу сохранится в вашем профиле и добавится в текущую очередь повторения.
4. **Импорт / Экспорт CSV и управление карточками:**
   - Нажмите иконку шестерёнки (**Настройки и словарь**).
   - В блоке **Мои карточки** можно искать и удалять добавленные вручную карточки.
   - В блоке **Импорт / Экспорт CSV** можно массово загружать карточки в формате `German;Russian;Example_DE;Example_RU;Context;Tags`.
5. **Горячие клавиши (на компьютере):**
   - `Пробел` — показать ответ.
   - `1` — Снова, `2` — Трудно, `3` — Хорошо, `4` — Легко.
   - `Esc` — закрыть открытое окно.
